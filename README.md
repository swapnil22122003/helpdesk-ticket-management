# IT Helpdesk & Ticket Management System

🚧 **Project Status: Under Development**

A full-stack IT Helpdesk and Ticket Management System designed to help users report technical issues and manage support requests efficiently. The system allows users to create and track support tickets, while administrators or support teams can manage, update, and resolve reported issues.

## 📌 Project Overview

The IT Helpdesk & Ticket Management System is designed to streamline the process of reporting and managing technical support issues.

Users can raise support tickets with relevant details such as issue description, category, and priority. The support team can manage tickets, update their status, and track the progress of reported issues.

This project is being developed to gain practical experience in full-stack application development, REST APIs, database integration, and cloud deployment.

---

## 🚀 Features

### Current / Planned Features

- User Registration and Login
- Create Support Tickets
- View and Track Tickets
- Update Ticket Status
- Ticket Priority Management
- Ticket Category Management
- Assign Tickets to Support Staff
- Admin Dashboard
- Role-Based Access Control
- RESTful API Integration
- MySQL Database Integration
